# HSE SAFE DRIVING CHALLENGE

Браузерный симулятор безопасного вождения (HSE): отвлекающие сообщения на телефоне, светофоры, пешеходы, конусы, парковки, отчёты.

- Играть (телефон горизонтально или компьютер): https://milka120321-dot.github.io/driving-sim/
- Настольная версия v2: https://milka120321-dot.github.io/driving-sim/desktop.html

Результаты сохраняются только в браузере того устройства, на котором проходили.

## Полный экран на iPhone
Safari → «Поделиться» → «На экран «Домой»» → запускать с иконки «HSE Safe Drive» (полноэкранно, без панелей браузера). На Android полный экран включается при первом касании.

## Уведомления
Телефон на экране не увеличивается: при новом сообщении он подсвечивается, слегка вибрирует и звучит; текст показывается полностью (1–2 последних). Сообщения-«клиффхэнгеры» обрываются на «…» — полный текст только если открыть (−10 баллов на ходу).
